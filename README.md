# 巨兽毁灭者 3D

可离线运行的第三人称城市破坏小游戏。控制哥斯拉移动、喷火、踩踏，摧毁建筑回血，对抗坦克、直升机、菊花侠和楼顶西装老板；打工人是提供助威的友军。

## 启动

保留整个目录，用浏览器打开 `kaiju-destroyer.html`。所有脚本和 Three.js 均为本地资源，无需安装依赖。

也可以在目录中运行本地预览：

```sh
node serve.cjs
```

打开 <http://127.0.0.1:4399/kaiju-destroyer.html>。如果该端口已有预览服务，直接使用；需要另一端口时运行 `PORT=4400 node serve.cjs`。本轮浏览器验证使用 localhost，没有重新验证 file 协议或手机真机。

## 本轮更新

- **菊花侠**：将原放屁侠升级为搞笑精英敌人，加入蓄气预警、背身喷气、喘气硬直与花瓣式背部弱点。弱点仅在喷气结束或被踩踏打断后开放；开放期间从背后喷火造成 5 倍伤害。闭合阶段从任何方向攻击均为普通伤害。
- **打工人**：三种工服配色，补齐衬衫、松领带、工牌、公文包和独立四肢；缩回普通人的体型。巡逻方向与走路一致，遇墙绕行，靠近玩家时抬手助威，显示“同事 / 友军”标识。
- **城市**：八款卡通商业建筑，包含彩盒公寓、阶梯写字楼、转角百货、爆米花影院、像素电玩中心、糖果双塔酒店、钟塔商馆和积木仓库。整栋统一选款、朝向和明度；L 形广场、退台和双塔写入实际地图与高度。每格可独立受损、倒塌，邻格消失后墙面保持完整。
- **其他角色**：坦克补齐履带、炮塔和炮管；直升机补驾驶舱、尾梁、滑橇和双旋翼；哥斯拉重做连续颈尾、三列背鳍、鳞甲、眼睛和爪。
- **老板**：保留此前重做的面部、眼镜、细条纹西装与训话动作；屋顶生成避开边缘，弹幕先越过脚下的屋顶再俯冲。

- **界面**：增加深色 HUD 底板、持续可见的助威人数、友军标签及窄屏暂停/声音/踩踏按钮。

## 操作

| 输入 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对镜头移动 |
| Shift | 冲刺 |
| 鼠标移动 | 瞄准，火焰自动喷射 |
| 空格 | 踩踏冲击波，冷却 2 秒 |
| P / Esc | 暂停与继续 |
| M | 静音与恢复声音 |
| 触屏左侧拖动 | 摇杆移动，推到底冲刺 |
| 触屏右侧拖动 / 轻点 | 瞄准 / 踩踏 |
| 窄屏或触控设备上的按钮 | 暂停、声音和踩踏 |

失去窗口焦点或切到后台时自动暂停；恢复后需按键或点击“继续”。

## 当前规则

- 城市为 72 × 72 格。摧毁建筑回血、加分；连击最高 10 倍。生存得分每秒 +10，不产生连击。
- 火焰最远 24 格，每 3 个模拟帧结算一次，每个目标单次伤害 2；同一轮不会重复扣同一格建筑血量。先碰到的可命中敌人或完整建筑阻挡后续火焰。
- 火焰 10 格内覆盖街面，更远处逐渐抬升，远处矮楼会被掠过。建筑和敌人使用相同高度规则。
- 踩踏半径 4 格，对地面敌人造成 8 点、建筑造成 5 点伤害；不伤友军、空中直升机或楼顶老板。
- 坦克、菊花侠和老板被火焰/踩踏击杀使用相同掉落结算；老板掉落 5 个血包。
- 第 10 波后敌方血量、伤害和分值每波增加 12%；每批数量有上限。
- 音效由 WebAudio 合成；最高分保存在本地浏览器，存储不可用时退回内存。

| 单位 | 行为与弱点 |
| --- | --- |
| 打工人 `soldier` | 随机巡逻，不攻击玩家，免疫玩家火焰和踩踏。8 格内且没有完整建筑遮挡时，每人给连击窗口 +0.5 秒，最多 4 人；敌方流弹可以误伤他们。 |
| 坦克 `tank` | 地面追击，发射炮弹，击杀掉落小血包。 |
| 直升机 `helicopter` | 在约 5 格高度飞行、射击，能飞过低于自身的建筑。 |
| 菊花侠 `fartHero` | 80 基础生命、12 基础弹道伤害。8 格内无遮挡时蓄气并锁定射线，背身喷气；喘气期间弱点开放，背后火焰伤害 ×5。气团命中使移速降低 40%，持续 1.5 秒。 |
| 老板 `boss` | 生成在有足够落脚空间的楼顶，相互保持距离。文字弹幕使火焰伤害短暂降低 40%；弹幕仍会被沿途其他高楼挡住。脚下楼塌后落地，可再用踩踏攻击。 |

### 菊花侠的应对方式

- 第 3 波首次保证登场，生成位置不足时继续重试；第 6 波起进入常规编制，同时最多存活 2 只。血量、伤害和分数沿用第 10 波后的成长规则。
- 蓄气 0.7 秒时出现固定方向预警，身体转到背朝射线的方向；此时背部弱点仍然闭合，横移可躲开锁定的弹道。
- 喷气动作持续 0.3 秒，只释放一枚由三团云表现的气弹；弹速为每秒 7.2 格，最大行程 8 格，完整建筑会挡住气弹。
- 喷气结束后喘气 1.2 秒，停位锁向并打开弱点。背后喷火造成 5 倍伤害，正面、侧面仍为普通伤害；恢复结束后再冷却 1.5 秒，期间继续追击。
- 踩踏造成原有 8 点伤害，并打断蓄气或喷气、立即打开弱点。已离体气团继续飞行；恢复期间再次踩踏不会延长开放时间。
- 击杀得 1000 基础分，并掉落一个恢复 15 HP 的血包。菊花侠保留内部类型名 `fartHero`，无需额外资源或依赖。

使用 `kaiju-destroyer.html?heroPractice=1` 可直接进入菊花侠练习场，快速体验预警、躲闪、打断和弱点攻击。

## 查看模型

- `city-preview.html`：八款建筑总览、单栋四向/俯视、三档明度、固定种子街区及外角/内部格拆除演示。

- `tests/scene-check.html`：固定种子场景，用于比较建筑、单位和 HUD；不作为正常游戏入口。
- `tests/hero-responsive-check.html`：以 390 / 320 像素文档宽度并排检查菊花侠展示、练习场和开始页。
- `tests/city-responsive-check.html`：以实际 390 / 320 像素文档宽度检查建筑展示和正式游戏。

## 当前边界

- 菊花侠和八款建筑均按用户确认方案实现；此前场景更新仍以项目 README 与 plan 为依据。
- 建筑保持逐格 Mesh，共享有限的几何/纹理缓存和距离阴影剔除；尚未改为实例化渲染。复杂场景和手机性能仍需继续实测。
- 敌人采用局部绕行，复杂街角的长距离寻路仍可能绕远。
- 玩家命中是半径 1.1 的躯干圆形，尾巴不参与判定；模型不是逐部位物理碰撞。
- 保留 classic script 离线结构和 Three.js r160，控制台有该版本的弃用提示。没有进行依赖升级。
