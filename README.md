# 巨兽毁灭者 3D

可离线运行的第三人称城市破坏小游戏。控制哥斯拉移动、喷火、踩踏，摧毁建筑回血，对抗坦克、直升机、放屁侠和楼顶西装老板；打工人是提供助威的友军。

## 启动

保留整个目录，用浏览器打开 `kaiju-destroyer.html`。所有脚本和 Three.js 均为本地资源，无需安装依赖。

也可以在目录中运行本地预览：

```sh
node serve.cjs
```

打开 <http://127.0.0.1:4399/kaiju-destroyer.html>。如果该端口已有预览服务，直接使用；需要另一端口时运行 `PORT=4400 node serve.cjs`。本轮浏览器验证使用 localhost，没有重新验证 file 协议或手机真机。

## 本轮更新

- **打工人**：三种工服配色，补齐衬衫、松领带、工牌、公文包和独立四肢；缩回普通人的体型。巡逻方向与走路一致，遇墙绕行，靠近玩家时抬手助威，显示“同事 / 友军”标识。
- **城市**：连续楼体、分层窗框、首层入口、檐口、外缘女儿墙和屋顶设备；人行道、路口标线与真实地图对应。每格仍可独立受损、倒塌，邻格消失后墙面保持完整。
- **其他角色**：坦克补齐履带、炮塔和炮管；直升机补驾驶舱、尾梁、滑橇和双旋翼；放屁侠补制服、披风和背部弱点；哥斯拉重做连续颈尾、三列背鳍、鳞甲、眼睛和爪。
- **老板**：保留此前重做的面部、眼镜、细条纹西装与训话动作；屋顶生成避开边缘，弹幕先越过脚下的屋顶再俯冲。
- **玩法与输入**：修正火焰射程、遮挡和重复伤害，流弹判定，连击计分、斜向加速、体积碰撞及暂停/重开残留输入。模拟固定为每秒 60 步，不再随显示器刷新率加速。
- **界面**：增加深色 HUD 底板、持续可见的助威人数、友军标签及窄屏暂停/声音/踩踏按钮。

详细问题、验证记录及前后截图见 [检查与修复记录](artifacts/audit/审查与修复.md)。

## 操作

| 输入 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对镜头移动 |
| Shift | 冲刺 |
| 鼠标移动 | 瞄准，火焰自动喷射 |
| 空格 | 踩踏冲击波，冷却 2 秒 |
| P / Esc | 暂停与继续 |
| M | 静音与恢复声音 |
| 触屏左侧拖动 | 摇杆移动，推到底冲刺 |
| 触屏右侧拖动 / 轻点 | 瞄准 / 踩踏 |
| 窄屏或触控设备上的按钮 | 暂停、声音和踩踏 |

失去窗口焦点或切到后台时自动暂停；恢复后需按键或点击“继续”。

## 当前规则

- 城市为 72 × 72 格。摧毁建筑回血、加分；连击最高 10 倍。生存得分每秒 +10，不产生连击。
- 火焰最远 24 格，每 3 个模拟帧结算一次，每个目标单次伤害 2；同一轮不会重复扣同一格建筑血量。先碰到的可命中敌人或完整建筑阻挡后续火焰。
- 火焰 10 格内覆盖街面，更远处逐渐抬升，远处矮楼会被掠过。建筑和敌人使用相同高度规则。
- 踩踏半径 4 格，对地面敌人造成 8 点、建筑造成 5 点伤害；不伤友军、空中直升机或楼顶老板。
- 坦克、放屁侠和老板被火焰/踩踏击杀使用相同掉落结算；老板掉落 5 个血包。
- 第 10 波后敌方血量、伤害和分值每波增加 12%；每批数量有上限。
- 音效由 WebAudio 合成；最高分保存在本地浏览器，存储不可用时退回内存。

| 单位 | 行为与弱点 |
| --- | --- |
| 打工人 `soldier` | 随机巡逻，不攻击玩家，免疫玩家火焰和踩踏。8 格内且没有完整建筑遮挡时，每人给连击窗口 +0.5 秒，最多 4 人；敌方流弹可以误伤他们。 |
| 坦克 `tank` | 地面追击，发射炮弹，击杀掉落小血包。 |
| 直升机 `helicopter` | 在约 5 格高度飞行、射击，能飞过低于自身的建筑。 |
| 放屁侠 `fartHero` | 转身较慢，绕后攻击可获得 5 倍伤害；绿色弹道造成短暂移速 -40%。 |
| 老板 `boss` | 生成在有足够落脚空间的楼顶，相互保持距离。文字弹幕使火焰伤害短暂降低 40%；弹幕仍会被沿途其他高楼挡住。脚下楼塌后落地，可再用踩踏攻击。 |

## 查看模型

- `boss-preview.html`：Boss 近景，拖动旋转、滚轮缩放，支持键盘、正反面和待机/训话切换。
- `tests/character-check.html`：全部角色的正面、背面、侧面及动画检查页，直接加载游戏模型模块。
- `tests/scene-check.html`：固定种子场景，用于比较建筑、单位和 HUD；不作为正常游戏入口。

## 当前边界

- 本轮对照的是项目中的 README 与 plan，未收到其他设计原稿。
- 建筑保持逐格 Mesh，共享有限的几何/纹理缓存和距离阴影剔除；尚未改为实例化渲染。复杂场景和手机性能仍需继续实测。
- 敌人采用局部绕行，复杂街角的长距离寻路仍可能绕远。
- 玩家命中是半径 1.1 的躯干圆形，尾巴不参与判定；模型不是逐部位物理碰撞。
- 保留 classic script 离线结构和 Three.js r160，控制台有该版本的弃用提示。没有进行依赖升级。
