# 八款卡通商业城验收记录

日期：2026-10-04。工作目录：`/Users/sad/code/4399`。

交付为本地可玩的城市和建筑展示页。正式地图、展示与自动检查使用同一个 `city-visual.js` 目录和模型；保留已有菊花侠功能及全部回归断言。本轮没有增加联网资源，也没有发布远程版本。

## 打开交付

在项目目录运行 `node serve.cjs`，服务只绑定本机 `127.0.0.1`：

- [正式游戏](http://127.0.0.1:4399/kaiju-destroyer.html)
- [八款建筑展示](http://127.0.0.1:4399/city-preview.html)
- [390 / 320 窄屏检查](http://127.0.0.1:4399/tests/city-responsive-check.html)

保留完整项目目录与 `vendor/three.min.js`。本轮浏览器检查使用 localhost；没有重新验证双击 HTML 的 file 协议。

## 实现结果

| 项目 | 结果 |
| --- | --- |
| 八款建筑 | 按批准尺寸、2–5 层体块和三色方案实现；每栋固定选用 92% / 100% / 108% 之一 |
| 建筑辨识 | 阳台、退台、L 形、爆米花徽记、像素阶梯、双塔凹口、四面钟盘、仓库锯齿檐口与宽卷帘门 |
| 城市布局 | 全部八款覆盖；中心商业、外围公寓/酒店/仓库；钟塔 1–2 栋；禁止水平或垂直连续三栋同款 |
| 通行与碰撞 | 道路和出生空地保留；L 形内侧实际为空格；高度与碰撞读取同一逐格数据 |
| 破坏 | 每格一个合并 Mesh，四面封闭，从地面倒塌；邻格破坏后重建外露构件；回血、计分仍只结算一次 |
| Boss 屋顶 | 每局至少四栋有平坦可站立 3×3 区域；须同栋同高、完整且无设备；电玩阶梯不可站立 |
| 资源 | 每款一个共享图集，三档明度共用纹理；发光仅覆盖电玩灯带，无动态光源；缓存键不含随机种子或绝对坐标 |
| 展示操作 | 八款总览、旋转/缩放、正背左右/俯视、明度切换、固定种子街区、拆外角/内部格与复原 |

| 固定街区 | 种子 4399 连续生成两次，名称与投影位置一致；35 栋、880 格、881 次主场景绘制（格子+地面）；2026 为 861 格、862 次 |
